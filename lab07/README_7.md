# Лабораторная работа №7: Итоговый проект (База данных маркетплейса)

Данная лабораторная работа представляет собой комплексный итоговый проект, объединяющий все наработки и технологии, изученные в рамках курса (Лабораторные работы №1–6), в единое готовое решение.

---

## Файлы проекта

| Файл | Назначение |
|---|---|
| [01_schema.sql](01_schema.sql) | Итоговая DDL-схема базы данных маркетплейса в 3НФ (14 таблиц со всеми ограничениями целостности) |
| [02_seed.sql](02_seed.sql) | Единый согласованный сид данных (100 пользователей, 1002 товара с JSONB, заказы с распределением по датам) |
| [03_logic.sql](03_logic.sql) | Серверная логика на PL/pgSQL (транзакционная функция `place_order`, расчёт выручки, триггеры аудита и рейтинга) |
| [04_views_and_reports.sql](04_views_and_reports.sql) | Аналитические представления (VIEW), рекурсивный CTE дерева категорий и отчёты на оконных функциях |
| [05_indexes.sql](05_indexes.sql) | Финальный набор продакшен-индексов (B-tree и GIN) с верификацией планов через `EXPLAIN ANALYZE` |

---

## Порядок запуска

Для полного развёртывания базы данных с нуля скрипты выполняются строго последовательно:

1. `01_schema.sql` — создание таблиц и связей.
2. `02_seed.sql` — наполнение данными.
3. `03_logic.sql` — компиляция серверных функций и триггеров.
4. `04_views_and_reports.sql` — создание витрин VIEW и выполнение аналитики.
5. `05_indexes.sql` — создание B-tree и GIN индексов.
